## Mission 10: The Enterprise Cloud Architect

Mission 10 was one of the most challenging parts of the course because it required us to use the knowledge we gained from the previous missions. Our task was to build and document an application environment using an Ubuntu Server virtual machine, Docker Compose, WordPress, and MySQL. We also needed to work on security, data storage, backups, automation, and project documentation.

One of our first challenges was setting up the virtual machine using Oracle VirtualBox. We needed to choose the right amount of memory, processor power, and storage. During the setup, we experienced problems such as freezing and unexpected interruptions. This taught us that we need to check our computer's available resources before running a virtual machine. We also learned that virtualization allows us to run another operating system on our computer without needing a separate physical machine.

After setting up the virtual machine, we started working with Ubuntu Server. Using the terminal helped us become more familiar with Linux commands, folders, files, permissions, and server settings. At first, using the terminal was difficult, especially when we encountered errors. However, as we continued practicing, we became more comfortable using commands and managing the server.

We also learned how to use Docker and Docker Compose to run our application. Our project used WordPress for the website and MySQL for storing its data. We learned that these two services have different purposes but need to work together for the application to function properly. Docker Compose made it easier to manage both services through one configuration file.

While working with Docker Compose, we also learned about images, environment variables, port mappings, and volumes. We understood that the configuration file contains the settings needed to run and connect the different services. We also learned that keeping files and folders organized makes the project easier to manage.

## Challenges and Problem-Solving Experience

During Mission 10, we faced different problems involving virtual machines, Docker containers, file permissions, configuration settings, and accessing our application. There were times when we needed to repeat certain steps, check our commands, and review our files to find out what went wrong.

These experiences taught us that making mistakes is part of learning, especially when working with technology. Instead of giving up when something did not work, we learned to check the problem and look for possible solutions. We also realized that copying commands without understanding them can cause more problems. It is important to know what a command does before using it.

Another challenge was working with limited computer resources. Running a virtual machine and several Docker containers requires enough memory, processing power, and storage. When our computer did not have enough resources available, it sometimes became slow or stopped responding properly. This helped us understand why checking and managing computer resources is important.

We also learned that finishing a task does not always mean that it is working correctly. For example, creating a backup script does not automatically mean that the backup was successful. We need to check if the backup file was created and make sure the process works properly. The same applies to scheduled tasks and other automated activities. We must test them to make sure they do what they are supposed to do.

These challenges helped us become more patient and independent when solving problems. We learned that technical work requires practice, testing, and the willingness to learn from mistakes.

## Security, Data Storage, and Automation

Another important part of our project was learning about security and protecting data. We worked with the Ubuntu Server firewall and learned why controlling network access is important. A website should not only work properly but should also be protected from unwanted access. Using firewall rules, setting proper permissions, and keeping important login information safe are some ways to protect a system.

We also learned about Docker volumes and how they help keep important data safe. Containers can be stopped or removed, so important files should not depend only on the container itself. Volumes allow data to remain available even when a container is replaced. This is important for WordPress because its website files and database information need to be saved.

Automation was another important lesson in Mission 10. We learned how Bash scripts can perform repeated tasks, such as creating database backups. We also learned that Cron Jobs can schedule these scripts to run automatically. These tools help save time and reduce the need to perform the same tasks manually.

However, we also learned that automated tasks need to be checked. Creating a script is not enough. We need to make sure it runs correctly, creates the expected files, and follows the schedule we set.

Through these activities, we understood that security, data storage, and automation are important parts of managing a reliable system. They help protect information, keep important data, and make system maintenance easier.
